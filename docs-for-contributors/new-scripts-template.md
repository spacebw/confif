# Template for making new useless script

{prefix} = comment prefix for that programming language.
{date} - date in format like `11 may 2026`.
{yourname} - your github username
{pl} - that programming language
{number} - strait number of script (for example, if last scriot for this programming language is 8, then use 9)


***


```
{prefix} ---------- MADE BY CONFIF ---------

{prefix} Useless {pl} script {number}
{prefix} Made by {yourname} {date}.

--- YOUR CODE HERE ---

{prefix} ---------- MADE BY CONFIF ---------

```
